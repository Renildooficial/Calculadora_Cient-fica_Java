🧮 Calculadora Científica em Java
Uma aplicação desktop desenvolvida em Java com interface gráfica no terminal (menu interativo), focada em simplicidade, precisão e facilidade de uso para operações matemáticas essenciais e científicas básicas.

🚀 Funcionalidades
➕ Operações Básicas: Adição, subtração, multiplicação e divisão.

📐 Funções Científicas:

Potenciação e raiz quadrada.

Funções trigonométricas (Seno, Cosseno, Tangente).

Logaritmos.

📋 Menu Interativo: Navegação simples e intuitiva via terminal/console.

🛡️ Tratamento de Erros: Validação de entradas (ex: prevenção de divisão por zero).

🛠️ Tecnologias Utilizadas
Linguagem: Java (JDK 8 ou superior)

Paradigma: Orientação a Objetos (POO)

📦 Como Executar o Projeto
Pré-requisitos
Certifique-se de ter o JDK instalado na sua máquina.

Passo a Passo
Clonar o repositório:

Bash
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
Acessar a pasta do projeto:

Bash
cd NOME-DO-REPOSITORIO
Compilar os arquivos Java:

Bash
javac Main.java
Executar a aplicação:

Bash
java Main
