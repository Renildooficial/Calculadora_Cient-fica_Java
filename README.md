<h2>📌 Sobre o Projeto</h2>

<p>
  A <b>Calculadora Científica</b> é uma solução desenvolvida em Java estruturada em Orientação a Objetos (POO). O projeto traz uma interface em menu interativo via console/terminal, combinando rapidez na execução e simplicidade no uso para operações matemáticas do dia a dia e cálculos científicos essenciais.
</p>

<br />

<h2>🚀 Como Executar o Projeto</h2>

<h3>1. Pré-requisitos</h3>
<p>Certifique-se de ter o <b>JDK (Java Development Kit)</b> instalado na sua máquina.</p>

<h3>2. Passo a Passo</h3>

<p>Clone o repositório para o seu ambiente local:</p>

```bash
git clone [https://github.com/Renildooficial/Calculadora_Cient-fica_Java]((https://github.com/Renildooficial/Calculadora_Cient-fica_Java/))
Bash
cd NOME-DO-REPOSITORIO
Bash
javac Main.java
Bash
